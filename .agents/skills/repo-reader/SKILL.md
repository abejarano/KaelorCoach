# Repo Reader

## Regla

Leer primero. No asumir estructura, comandos, frameworks o contratos.

## Lectura mínima

- `README.md`
- `AGENTS.md`
- `CODEX.md`
- `feature_list.json`
- `progress/current.md`
- `docs/PRODUCT.md`
- documentación de la superficie.
- archivos de configuración reales.

## Resultado previo a implementar

Documentar en el plan:

- contexto detectado;
- stack real;
- módulos involucrados;
- patrones existentes;
- scripts reales;
- archivos a tocar;
- riesgos y bloqueos.
